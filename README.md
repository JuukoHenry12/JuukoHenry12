## Selected Work

**ICD Operations Platform** — *Masstra Shipping Agents Ltd*
Operations platform for an Integrated Container Depot: yard slot allocation, gate
control, weighbridge, finance and HSE modules. Spring Boot service on PostgreSQL with
a generic typed-record layer, versioned REST endpoints, optimistic locking via
ETag/If-Match, and a permission model with segment-wise wildcards driving both route
guards and field-level editability. Front end migrated from vanilla HTML/JS to Next.js
with Zustand and Tailwind. Deployed via Docker.

`Spring Boot` `PostgreSQL` `Next.js` `Zustand` `Docker` `JWT`

**SaleAgent** — *sales management system*
Spring Boot and Angular application covering customers, agents, quotations, sales
orders, invoices, payments and follow-ups. Three-tier role hierarchy with row-level
data scoping enforced through Spring Security method annotations. Angular front end
built on NgRx Signal Store with reusable table and dialog components.

`Spring Boot` `Spring Security` `Angular` `NgRx Signal Store`

**Mobile Money Payment Microservice**
Spring Boot microservice targeting Uganda's mobile money ecosystem — provider
integration, transaction lifecycle handling and reconciliation.

`Spring Boot` `REST` `Microservices`

**Multilingual Health Assistant**
Machine learning project exploring health information access in African languages.

`Python` `NLP` `Machine Learning`

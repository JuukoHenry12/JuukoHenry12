## Selected Work

### ICD Operations Platform
> Operations platform for an Integrated Container Depot — yard slot allocation, gate control, weighbridge, finance and HSE modules. Spring Boot on PostgreSQL with a generic typed-record layer, versioned REST endpoints, optimistic locking via ETag/If-Match, and a permission model with segment-wise wildcards driving route guards and field-level editability. Front end migrated from vanilla HTML/JS to Next.js. Deployed via Docker.

![Spring Boot](https://img.shields.io/badge/-Spring%20Boot-6DB33F?style=flat-square&logo=springboot&logoColor=white)
![PostgreSQL](https://img.shields.io/badge/-PostgreSQL-4169E1?style=flat-square&logo=postgresql&logoColor=white)
![Next.js](https://img.shields.io/badge/-Next.js-000000?style=flat-square&logo=nextdotjs&logoColor=white)

![JWT](https://img.shields.io/badge/-JWT-000000?style=flat-square&logo=jsonwebtokens&logoColor=white)

### SaleAgent
> Sales management system covering customers, agents, quotations, sales orders, invoices, payments and follow-ups. Three-tier role hierarchy with row-level data scoping enforced through Spring Security method annotations. Angular front end on NgRx Signal Store with reusable table and dialog components.
